# MatrixMedia

Independent media streaming service for the Matrix ecosystem.

## Status

Phase 0 -- Project scaffold. Not yet functional.

## Quick Start

```bash
# Start dev infrastructure
cd infra/docker && docker compose up -d

# Build and run
cargo run -p mm-server -- serve
```
