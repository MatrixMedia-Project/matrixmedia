Run your own server

Your own Matrix server with chat, calls, live streaming and creator tools. Free and open source.

Try it on your computer

Everything runs in one Docker container. You need Docker, nothing else.

docker run -d --name matrixmedia \
  -p 8008:8008 -p 7881:7881 -p 7882:7882/udp -p 50100:50100/udp \
  -e MM_PUBLIC_HOST=127.0.0.1 \
  -v matrixmedia-data:/data \
  ghcr.io/matrixmedia-project/matrixmedia-allinone:dev

Wait until docker ps shows it as healthy. Then get your admin login with docker exec matrixmedia mm-allinone credentials and open http://127.0.0.1:8008/.

This is for trying it out, not for real use. Payments are fake. To use it from a phone on your Wi-Fi, see the full try-it guide.

Install it on a server

One command sets up the whole server and takes about five minutes. You need:

  • A Linux server with Ubuntu or Debian on a regular x86-64 CPU (ARM servers aren’t supported yet)
  • At least 4 GB of RAM and 20 GB of free disk
  • A public IPv4 address, with nothing else using ports 80 and 443
  • A domain name you can add DNS records to (you can skip this to just try it)
Step-by-step install guide Guide for AI agents

The guide shows the command, the DNS records and the firewall ports, and how to read the installer before you run it.

After you install

  • Sign in to the Operator Console at https://matrix.<your-domain>/_mm/dashboard/ to manage your server.
  • People connect with the MatrixMedia apps, Element or FluffyChat by entering your server’s address.
  • sudo mmctl doctor checks the server. sudo mmctl backup makes a backup.

Questions or problems? Open an issue on GitHub. The source code is there too.
