# MatrixMedia JVM SDK

Desktop JVM bindings for the Matrix protocol, built on a forked / rebuilt
[`matrix-rust-sdk`](https://github.com/matrix-org/matrix-rust-sdk) exposed
through [UniFFI](https://mozilla.github.io/uniffi-rs/).

This module produces a single fat `.jar` containing:

- Kotlin/JVM API generated by `uniffi-bindgen-kotlin`
- Native shared libraries for each supported desktop triple, packed under
  `src/main/resources/{os}-{arch}/`

## Status

Scaffold only. No working build yet. The structure here mirrors the pattern
used by the Mages project (AGPL — read for reference, **never vendored**),
specifically how their `core/` Cargo workspace is wired into a Kotlin JAR by
a Gradle build script.

## Layout

```
sdks/jvm/
├── README.md                       this file
├── Cargo.toml                      Rust workspace root (separate from main
│                                   matrixmedia workspace)
├── ffi/                            UniFFI crate — wraps matrix-rust-sdk-ffi
│   ├── Cargo.toml
│   ├── build.rs
│   ├── matrix_sdk_ffi.udl
│   └── src/lib.rs
├── kotlin/                         Gradle Kotlin/JVM module
│   ├── build.gradle.kts
│   ├── settings.gradle.kts
│   └── src/main/kotlin/com/matrixmedia/jvm/
├── scripts/
│   ├── build-all.sh                cross-compile all triples
│   └── package-jar.sh              copy native libs into resources/
└── docs/BUILD.md                   detailed walkthrough
```

## Supported targets (planned)

| OS      | Arch    | Triple                          |
| ------- | ------- | ------------------------------- |
| Windows | x86_64  | `x86_64-pc-windows-msvc`        |
| Linux   | x86_64  | `x86_64-unknown-linux-gnu`      |
| Linux   | aarch64 | `aarch64-unknown-linux-gnu`     |
| macOS   | x86_64  | `x86_64-apple-darwin` (later)   |
| macOS   | aarch64 | `aarch64-apple-darwin` (later)  |

## Build

See [docs/BUILD.md](docs/BUILD.md). TL;DR (once toolchains exist):

```bash
./scripts/build-all.sh
./scripts/package-jar.sh
cd kotlin && ./gradlew jar
```
